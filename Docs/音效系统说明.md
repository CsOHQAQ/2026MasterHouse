# 音效系统说明

> 落地日期：2026-08-12。对应策划音效需求清单「音效需求——11 个」（8 大类）。
> 音频源文件：`Assets/Resources/SoundEffect/`（12 个 mp3，文件名 = 需求编号_语义_日期）。

## 0. 首次启用（必做一次）

代码已全部接好，但音效表资产需要在 Unity 里生成一次：

1. 打开 Unity，等编译完成（会自动生成新脚本的 .meta）。
2. 执行菜单 **MasterHouse → 音效系统 → 创建音效表（补齐缺失）**——生成 `Assets/Resources/OutGameUI/SfxTable.asset` 并按文件名前缀自动匹配全部剪辑。
3. 进 OutGameTest 场景冒烟。缺表时 Console 会报错并指向该菜单，不会静默无声。

音效表也已注册进 **配置中心**（MasterHouse → 配置中心）的「音效」分组。

## 1. 架构：一表一管理器，播放点只写 ID

```
SfxTable.asset（Model，运行时只读，§16.6）      HouseSettings（sfxVolume 0~100，§16.5 设置文件）
   ESfx → 剪辑 / 音量倍率 / 节流间隔                        │
        └──────────────┬───────────────────────────────────┘
                       ▼
              SfxManager（View 层全局单例，DontDestroyOnLoad）
              · 唯一出口：SfxManager.Play(ESfx.Xxx)，fire-and-forget
              · 单 AudioSource + PlayOneShot（多音自然混音）
              · 同 ID 按 minInterval 节流（防同帧叠爆；打字机节奏也靠它）
              · 订阅业务事件自动发声（见 §2 第 4/6 条）
                       ▲                        ▲
        UI 交互音：各 View 直接调 Play      业务事件音：VisitorManager / EconomyManager 的
        （点击/转场/拖拽/推进）              事件广播，业务代码零音频调用（MVVM 分层不破）
```

三个代码文件（Core 模块，局内局外通用）：

| 文件 | 职责 |
|---|---|
| `Assets/Scripts/Core/SfxTable.cs` | `ESfx` 枚举（11 个 ID + None）、`SfxEntry`、`SfxTable` SO |
| `Assets/Scripts/Core/SfxManager.cs` | 全局播放器：加载表、音量、节流、订阅业务事件 |
| `Assets/Scripts/Core/Editor/SfxConfigSetupUtility.cs` | 建表菜单：只补缺失不覆盖，剪辑按前缀自动匹配 |

拉起时机：`OutGameBootstrap` 在 GameManager 之后、界面壳之前 `SfxManager.Ensure()`（进场即订阅访客/经济事件）。`Play` 内部有惰性兜底，早于拉起的调用不炸。

**约定：**
- 播放点一律 `SfxManager.Play(ESfx.Xxx)`，禁止散落 `AudioSource`/直接引用剪辑。
- 换音 / 调音量 / 调节流 = 改 `SfxTable.asset` 的 Inspector，不碰代码。
- `ESfx` 枚举值已显式赋值并序列化进资产，**新增只能追加，不得改已有值**。
- 音效属表现层：只订阅业务事件、只读状态，绝不回写业务（§16.4 表现层豁免边界）。

## 3. 刻意不响的场合（防叠音/防噪音的设计决定）

| 场合 | 原因 |
|---|---|
| 访客卡、对话推进/选项按钮的基础点击音 | `BindButton(..., ESfx.None)` 关掉——这些按钮响的是更具体的交互音（#3），不叠基础点击 |
| 商城购买的扣款负向音 | 购买的反馈就是那声 `Reward`（获得弹窗），扣款再响负向音语义打架 |
| GM 后门（`GmAdd*`） | 调试操作，`Feedback` 事件刻意不发；GM 面板按钮本身的点击音照常 |
| 装饰分回写（`SetFurnitureDecorationScore`） | 每次摆放家具都会重算，若发声会与摆放音（#2）每次都叠响 |
| 全屏遮罩（scrim）点击关面板 | 3 处无手感组件的遮罩按钮保持静音——遮罩不是「普通按钮」 |
| 无效操作 | 分支未选点空白、家具无效落点、点已离开的访客等：不响，静默即反馈 |

## 3.5 剪辑直传：循环音通道与专属一次性音（2026-08-20 新增）

音效表之外的第二套口径：**剪辑由调用方直传**，配在它自己的 Prefab / Def 上。
某个玩法的专属音走这条——配在就近的地方，换音不会牵动全局的通用音。

```csharp
SfxManager.SetLoop(clip, on, volumeScale);   // 循环音：一个剪辑 = 一路常驻 AudioSource
SfxManager.RefreshLoopVolumes();             // HouseSettings.Apply 推送，播放中改音量实时生效
SfxManager.PlayOnce(clip, volumeScale);      // 一次性音：直传版的 Play，不节流
```

（家具的专属拿起/放下音走 `PlayOverride(clip, fallback)`，是 `PlayOnce` 加一层「空则回落到表内音效」。）

`SetLoop` 的额外约定：

- **同状态是空操作**，所以可以逐帧调，直接由「本帧该不该响」这个布尔驱动，调用方不用记上一帧。
- **硬起硬停**，不做淡入淡出；停过之后再开是**从头播**（`Stop()` 会把播放位置归零）。
- 剪辑传 `null` 直接返回 = 该处静音，不报错。
- 音量 = 设置页「音效」× `volumeScale`，与一次性音同一条音量链。

**BGM 临时压低**：`BgmManager.SetDuck(0~1)`，与设置页「背景音乐」是**相乘**关系（压低期间玩家改设置照样生效）。
谁压低谁负责恢复——调用方的结束 / 放弃 / 销毁三条路都要调 `SetDuck(1f)`。

**使用者 ①：制作咖啡小游戏**（`CoffeeMinigame`）

默认剪辑虽然复用全局素材，但**是独立引用**——换成电路专属素材时改 Prefab 上的引用即可，不会动到家具拿起音 / 基础点击音 / 声望增减音。
注意 `2_Pickup_260813_1` 与 `4_ScoreLose_260813_1` 跟音效表里那两条（`_260812` 版）**不是同一个文件**。

电池状态音的收口在 `CircuitBoard.CommitLayoutChange`：增删线、摆件、挪件、删件五条改布局的路径全走它，
先比对上一次的满足集合（`litNodes`）再发 `LayoutChanged`。同一次操作既点亮又弄灭时**正向优先只响一声**。
换关由 `SeedLitBaseline` 静默重置基线——翻页看到的是上次留下的布线，不该被当成刚做成的事而响一片音。

修理电路**刻意不响**的场合：右键删线 / 删件（静默即反馈）；连线失败（没描到接口的静默作废、超预算被拒、
接口已占用）——界面上已有文字说明；「一直没满足」的中间态；BGM 也不压低（这是安静的解谜，没有要让位的持续音）。

> ⚠ `CoffeeMinigame` / `CircuitBoard` 因此引用了 `SfxManager`（前者还有 `BgmManager`），是 §8.5
> 「小游戏不认识任何 Manager」的一处窄口豁免：那条约束管的是**业务** Manager 与宿主类型，
> 音频这两位是 View 层的全局出口，只发声、不读写业务状态。理由写在两个类的类注释里。

## 4. 常见改动怎么做

- **换某个音效**：选中 `Resources/OutGameUI/SfxTable.asset`，在对应条目换 `clip`。
- **调某个音效音量**：同上调 `volume`（0~2 倍率，乘在全局音量上）。
- **打字机节奏**：调 DialogueTyping 条目的 `minInterval`（秒/次）。
- **加一个新音效**：①`ESfx` 追加新枚举项（显式赋值，勿动已有值）②表里加条目配剪辑 ③播放点写一行 `SfxManager.Play(ESfx.新ID)`；若想被建表菜单自动匹配，给 `SfxConfigSetupUtility.Mapping` 加一行前缀映射。
- **全局音量**：`HouseSettings.Data.sfxVolume`（0~100），存 `persistentDataPath/house-settings.json`，每次播放实时读取——改完立刻生效，无需重启。
