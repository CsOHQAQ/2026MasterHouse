# 导表工具说明

> 版本：v1.0（2026-08-11）。覆盖家具两表的 Excel → CSV → Unity 资产全链路。
> 快速上手看 `Tools/导表/README.md`；本文是完整沉淀：设计决策、表格规范、扩展方法与故障排查。
> 模式参考 CatVsDog 的 `export_config.bat`（总入口 bat + 每表一个导出脚本 + 产物直接落进 Assets）。

## 1. 一句话概括

策划在 **Excel/*.xlsx** 里编辑（唯一数据源），双击 **Tools/导表/export_config.bat** 展平成
**Assets/Configs/*.csv**，Unity 资产管线感知到 CSV 变化后**自动整表重建**对应 ScriptableObject——
Unity 开着关着都不需要额外步骤。

```
Excel/家具表.xlsx、家具房间表.xlsx        ← 策划编辑（唯一数据源）
        │  双击 Tools/导表/export_config.bat
        │  （检查 python/openpyxl → export_furniture.py / export_furniture_room.py）
        ▼
Assets/Configs/家具表.csv、家具房间表.csv  ← 自动生成，勿手改
        │  CSV 在 Assets 内：导入管线触发 CsvPostprocessor → FurnitureCsvImporter 自动导表
        │  （Unity 开着：切回窗口即导；关着：下次打开时导——无需 batchmode）
        ▼
FurnitureTable.asset / FurnitureRoomTable.asset（Resources/OutGameUI）
```

## 2. 目录与文件

| 位置 | 内容 |
|---|---|
| `Excel/` | 两本 xlsx（编辑源）。**只放表格**，工具脚本不进这里 |
| `Assets/Configs/` | 导出的 CSV（UTF-8 BOM）。在 Assets 内是刻意设计：资产管线才能感知变化 |
| `Tools/导表/` | `export_config.bat`（总入口）、`export_furniture.py`、`export_furniture_room.py`、`README.md` |
| `Assets/Scripts/Furniture/Editor/FurnitureCsvImporter.cs` | Unity 侧导入器：CSV → SO 整表重建、自动导表开关、导出回写 |

依赖：python + openpyxl（bat 检测到缺 openpyxl 会自动 `pip install`）。

## 3. 日常使用

| 场景 | 操作 |
|---|---|
| 改数值/加行 | 改 xlsx → 双击 bat → 切回 Unity（自动导表，Console 打 `[导表] 完成`） |
| Unity 开着想立即导 | 菜单 `MasterHouse → 家具系统 → 从 CSV 导入家具两表`（或配置中心里的按钮） |
| 关掉自动导表 | 菜单 `MasterHouse → 家具系统 → 自动导表（CSV 变化时）`（勾选开关） |
| 从资产反向生成 CSV | 菜单 `MasterHouse → 家具系统 → 导出家具两表到 CSV`。**只回写 CSV，不回写 xlsx** |
| 配置中心入口 | `MasterHouse → 配置中心`（Ctrl+Shift+M）里有导入/导出/打开 Excel 目录按钮 |

**心智模型：导入是整表重建，以表格为准。** Inspector 里对这两张 SO 的手改会在下次导表时被覆盖——
要么改表格，要么别导表，一个字段只能有一个家。

## 4. 表格规范（xlsx 通用约定）

- **第 1 行 = 中文列名**（导出/导入按列名索引，列顺序可在 Excel 里随意调整，但列名文字不能改）。
- **第 2 行 = Unity 字段名**（灰色斜体，如 `id` / `displayName` / `tableSurface.enabled`）——纯参考行，
  导出脚本检测到"全 ASCII 标识符"会自动跳过。
- **行序即资产内条目顺序**（收纳栏、商店列表的展示顺序）。
- **多选值用 `/` 分隔**（也兼容 `、` `,`），如表面类型 `地面/桌面`。
- **布尔列填 `是`/`否`**（兼容 1/true）。
- **图片列两种写法**：
  - Resources 相对路径（不带扩展名）：`OutGameUI/Furniture/table`
  - Assets 完整路径（带扩展名）：`Assets/PC ui/Scene/furniture/002_red_armchair 1.png`
  - SO 存的是 Sprite 引用，运行时不经路径加载，素材**不必**位于 Resources。
- 空行自动跳过；缺 id 的行跳过并打 Warning。

## 5. 家具表.xlsx（工作表「家具」→ FurnitureTable）

| 列 | 字段 | 说明 |
|---|---|---|
| id | id | 唯一稳定键，摆放/存档/商店引用它 |
| 显示名 | displayName | 界面显示 |
| 分类 | category | 商店页签：`盆栽`/`摆件`/`桌椅`/`壁挂`/`灯具`（空值按摆件） |
| 描述 | description | 商店详情与获得弹窗文案（空则显示占位句） |
| 表面类型 | surfaces | **可多选**：`地面`/`桌面`/`壁挂`，`/` 分隔；决定能吸附哪类网格、出现在哪些收纳页签 |
| 占格列/占格行 | cols/rows | 占用网格尺寸 |
| 显示宽/显示高 | displayWidth/Height | 场景像素。当前批素材按源图 ×0.18 拍的初值 |
| 价格 | price | **0 = 初始拥有**（默认摆放的家具都应为 0） |
| 解禁声望 | unlockReputation | 未达到时商店/收纳呈「？」 |
| 装饰分 | decorationScore | 摆放后对 House 装饰分的贡献 |
| 精灵图 | sprite | 见 §4 图片列 |
| 桌面格启用 + 5 参数 | tableSurface.* | 仅带桌面的家具（茶几等）填；列数/格宽/格高/偏移X/桌面高度 |

## 6. 家具房间表.xlsx（四张工作表 → FurnitureRoomTable）

明细行通过「房间id」挂到房间；坐标与尺寸全部为场景图像素（原点左上、Y 向下，场景逻辑尺寸 1672×941）。

| 工作表 | 列 | 说明 |
|---|---|---|
| 房间 | 房间id、显示名、场景宽/高、背景图、景深模糊图、失焦模糊图、初始货币 | 行序 = Hub 房间下标（0~3 对应起居室/卧室/厨房/书房） |
| 网格 | 房间id、网格id、表面类型、列数、行数、格宽、格高、X、Y | 当前为全图开放：壁挂 27×9@(26,20)、地面 27×8@(26,581) |
| 占用格 | 房间id、网格id、列、行 | 背景画面里禁止摆放的格子（新空房间图无占用格） |
| 初始摆放 | 房间id、家具id、网格id、宿主家具id、列、行、翻转 | 地面/壁挂填网格id；桌面家具填宿主家具id（二选一）；翻转=左右镜像 |

注意：**默认摆放只在该房间从未动过家具时生效**；正在 Play 需重进或 GM 重置才能看到新默认。

## 7. 自动化细节（Unity 侧）

- **触发**：`FurnitureCsvImporter.CsvPostprocessor`（AssetPostprocessor）监听
  `Assets/Configs/家具表.csv`、`家具房间表.csv` 的导入事件 → `EditorApplication.delayCall` 里执行导表。
- **Sprite 自愈**：表里引用的 `Assets/` 素材若没按 Sprite 类型导入（3D 模板默认 Default），
  导入器自动改 TextureImporter 为 Sprite/Single 并重导后重取引用。
- **防回环**：菜单「导出到 CSV」写文件前置 `suppressNextAutoImport`，跳过随之而来的一次自动回导。
- **合法性**：房间行必须排在其明细行之前（导出脚本已保证顺序）；引用不存在房间/丢失精灵会打 Warning 但不中断。

## 8. 新增一类配置表的步骤

以「新表 X」为例（照抄家具表的模式）：

1. `Excel/X表.xlsx`：第 1 行中文列名 + 第 2 行英文字段名。
2. 复制 `Tools/导表/export_furniture.py` 为 `export_x.py`：改 `EXCEL_PATH`/`OUTPUT_PATH`/`HEADER`/`SHEET`。
3. `export_config.bat` 加一步：`python "%~dp0export_x.py"` + errorlevel 检查。
4. Unity 侧在 `FurnitureCsvImporter`（或新建 `XCsvImporter`）加：CSV 路径常量、表头数组、
   Import 方法（`LoadOrCreate<XTable>` + 逐行解析）、`CsvPostprocessor` 监听路径。
5. 若表里有图片引用，直接复用 `LoadSprite`（两种路径写法 + 自愈都是现成的）。

## 9. 故障排查

| 现象 | 原因与处理 |
|---|---|
| bat 报 `PermissionError` / 写入失败 | xlsx 正被 Excel 打开锁住——关掉再跑 |
| bat 提示需要 python | 装 python 并加入 PATH；openpyxl 缺失时 bat 会自动 pip install |
| bat 出现乱码/命令不识别 | bat 必须保持**纯 ASCII**（当前提示语为英文即为此），别往里加中文 |
| 切回 Unity 没触发导表 | 检查菜单「自动导表（CSV 变化时）」是否被关；或手动菜单导入 |
| Console 报「精灵图未找到」 | 路径写错（对照 §4 两种写法），或素材未导入——该行 sprite 置空不中断 |
| 表里改的没生效 | 确认跑过 bat（CSV 时间戳变了）且 Unity 已聚焦；Inspector 手改会被导表覆盖属正常 |
| 家具在场景里比例不对 | 改「显示宽/高」；素材源图与场景的换算基准见家具表初值说明（×0.18 起步目测校准） |
