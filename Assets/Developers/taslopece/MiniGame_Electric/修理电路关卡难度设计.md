# 修理电路关卡难度设计

> 文档定位：基于当前修理电路机制，整理关卡能够使用的难度维度、组合方法、风险与评审口径，供策划搭建教学关、普通关和综合关。
>
> 关联文档：`修理电路关卡设计指南.md`、`修理电路关卡原型-节点与美术包装需求.md`。
>
> 状态：难度设计基准。具体关卡数值、件库数量、导线预算与评分目标仍需逐关填写解法证明并通过实玩验证。

---

## 1. 难度设计目标

修理电路的难度不应来自倒计时、操作惩罚或隐藏规则，而应来自玩家对**空间、电量和线路结构**的理解。

一关产生有效难度，通常需要同时满足：

1. 玩家能够看见所有关键条件；
2. 玩家可以解释自己为什么失败；
3. 解法要求做出至少一个有意义的取舍；
4. 找到解法后，线路结构比尝试过程更简洁；
5. 普通玩家可以获得部分完成，钻研玩家可以追求满分。

本项目整体方向是低压力体验。因此，难度主要服务于“发现更好的修法”，而不是阻止玩家继续体验。

---

## 2. 难度的总体结构

当前机制可以归纳为八个难度维度：

| 难度维度 | 核心问题 | 定位 |
|---|---|---|
| 空间布局 | 线路和节点怎样摆放才不会互相堵死？ | 核心维度 |
| 端点与 Pin | 从哪里接入、朝哪个方向接近目标？ | 辅助空间维度 |
| 电量计算 | 怎样通过分流、合流和损耗得到目标值？ | 核心维度 |
| 电路拓扑 | 应该先分后合、先合后分，还是让线路共享结构？ | 核心维度 |
| 中转件预算 | 稀缺件应该花在哪里？ | 核心资源维度 |
| 导线预算 | 应该走短路、绕行，还是用元件换距离？ | 辅助资源维度 |
| 多目标与评分 | 哪些目标优先，是否值得追求全部点亮？ | 核心取舍维度 |
| 固定骨架与权限 | 哪些旧结构值得保留、移动或拆除？ | 主题化综合维度 |

其中，空间、电量、拓扑、资源和目标取舍构成主要思考；Pin 朝向、导线长度与固定骨架更适合修饰或强化主考点。

## 3. 八个难度维度

### 3.1 空间布局

空间维度来自节点与导线都占据画布格子，且不能互相穿越。

可调整内容：

- 画布宽高与特殊形状；
- 不可走区域、凹槽、孤岛和设备结构；
- 电源与电池之间的距离；
- 是否存在单格或双格窄道；
- 多条线路是否争夺同一通道；
- 中转件是否有足够的合法落点；
- 节点尺寸是否会堵住其他线路；
- 是否同时存在短路径与长绕行路径。

有效难度：

- 玩家需要安排哪些线路先通过关键区域；
- 某个元件的摆放位置会影响其他线路；
- 最短路线和最容易理解的路线并不相同。

伪难度风险：

- 单纯扩大画布；
- 单纯拉长电源和电池距离；
- 让玩家反复描画没有决策意义的长线；
- 用低对比背景隐藏不可走区域。

### 3.2 端点与 Pin

端点维度决定线路从哪里出发、从哪里进入，以及中转件能否在空间中成立。

可调整内容：

- 电源输出 Pin 的数量和朝向；
- 不同输出 Pin 的独立电量；
- 电池输入 Pin 的数量和朝向；
- 一 Pin 一线造成的接口竞争；
- 中转件入口、出口的位置；
- 十字件不同 `PinGroup` 的配对关系；
- Pin 是否朝向狭窄空间或障碍。

有效难度：

- 玩家必须从特定方向接近目标；
- 同一个输出 Pin 不能被两套方案重复使用；
- 元件位置正确，但朝向使线路无法成立。

公平性要求：

- Pin 朝向、输入输出和分组必须在画面上可见；
- 接口占用后必须有明确状态；
- 不应靠“玩家没看清 Pin 在哪”制造失败。

### 3.3 电量计算

当前电量机制提供六种基本数值动作：

| 动作 | 示例 |
|---|---|
| 直接传递 | `5 → 5` |
| 合流求和 | `2 + 3 → 5` |
| 整除分流 | `6 ÷ 2 → 3 + 3` |
| 向下取整 | `7 ÷ 2 → 3 + 3，余数 1 消失` |
| 空出口损耗 | `6 ÷ 2 → 使用一路 3，另一路浪费` |
| 组合变换 | `8 ÷ 4 × 3 → 6` |

可调整内容：

- 电源输出数值；
- 电池需求数值；
- 电池是否允许过量；
- 分流器的输出口数量；
- 合流器的输入口数量；
- 是否需要主动制造损耗；
- 多个电源可以组成哪些候选组合。

推荐的数值难度顺序：

1. 直接匹配；
2. 两数合流；
3. 可整除分流；
4. 余数损耗；
5. 空出口主动损耗；
6. 分流与合流组合；
7. 多电源、多目标组合。

风险：

- 数值过大、质数过多会把空间谜题变成口算题；
- “过量不亮”“空出口参与分母”“余数消失”没有反馈时会被误认为 Bug；
- 同一关不宜同时引入多个未教学的数值规则。

### 3.4 电路拓扑

拓扑维度关注电路整体结构，而不只是单个数值。

可调整内容：

- 先分流还是先合流；
- 哪些线路共用一个中转件；
- 哪些线路必须交叉；
- 是否需要十字件避免混线；
- 一份电源应该服务哪个子网络；
- 数学最优结构与空间可摆结构是否冲突；
- 是否存在会被拒绝的回环；
- 是否存在多个结构不同但同分的解。

有效难度通常表现为两个正确判断发生冲突：

> 数学上先合流最简单，但合流器放在最佳位置会堵住唯一通道，所以必须换一种结构。

拓扑是最容易产生“顿悟”的维度。综合关应优先提高拓扑关系，而不是继续增加数值规模。

### 3.5 中转件预算

`BuildableNodes[].MaxCount` 限制每类中转件在场上的总数量。

可调整内容：

- 可用中转件种类；
- 每种中转件的数量；
- 是否缺少一个看似最直接的关键件；
- 某个中转件是否能被多条线路共享；
- 是否允许用更长导线替代稀缺元件；
- 是否存在功能相近但空间形状不同的件型。

有效难度：

- 十字件只有一个，必须选择最值得解决的交叉点；
- 合流器不足，迫使玩家改变电源组合；
- 二分器既能服务多个目标，也能用来主动损耗。

风险：

- 预算太紧会形成难以诊断的唯一解；
- 件库塞入大量无用件只会制造信息噪音；
- 教学关第一次使用某种件时不应同时限制到极限。

### 3.6 导线预算

`MaxLinkCells` 限制全部导线路径格数之和。

可调整内容：

- 总导线格数上限；
- 端点距离；
- 障碍造成的绕行长度；
- 十字件短路与外圈绕行的差值；
- 普通解和完美解之间需要节省的格数。

推荐定位：

- 基础完成：预算宽松，允许玩家用容易理解的路线通关；
- 优化完成：需要避免明显绕路；
- 完美完成：要求共享结构或接近最短路线。

风险：

- 预算只差一格往往带来挫败，而非顿悟；
- 玩家若看不到当前使用量和上限，无法规划；
- 不宜一开始就依靠极限线长制造主要难度。

### 3.7 多目标与评分

当前得分由点亮电池比例决定，因此电池数量也决定评分粒度。

| 电池数量 | 常见评分层级 |
|---:|---|
| 1 | 0 / 100 |
| 2 | 0 / 50 / 100 |
| 3 | 0 / 33 / 67 / 100 |
| 4 | 0 / 25 / 50 / 75 / 100 |

可调整内容：

- 电池数量；
- 各电池需求是否相同；
- 是否同时存在允许过量和精确供电目标；
- 容易目标与困难目标的位置；
- 不同目标是否争夺同一电源、Pin、通道或中转件；
- 保底解、优化解和完美解分别点亮哪些电池。

推荐结构：

- 保底解：理解主要规则即可得到 50 分左右；
- 优化解：加入一个旧机制的组合，得到 75 分左右；
- 完美解：同时解决本关的空间、数值或资源冲突，达到 100 分。

多目标的价值不是单纯增加工作量，而是允许玩家自己决定“修到什么程度”。

### 3.8 固定骨架与编辑权限

固定骨架把抽象搭建转化为“维修已有设备”。

可调整内容：

- 预置中转件数量；
- 哪些中转件不可移动；
- 哪些可以移动但不可删除；
- 哪些可以移动和删除；
- 旧骨架中哪些结构正确、哪些位置不佳；
- 件库只提供哪些补件；
- 保留旧结构与完全重搭分别消耗多少元件和导线。

有效难度：

- 保留旧件可以节省中转件，但会增加绕行；
- 移动旧件可以缩短线路，但会删除附着导线；
- 固定骨架给出解法提示，却并不直接完成答案。

风险：

- 错误骨架太多会像清理垃圾；
- 固定件与可移动件没有视觉区分时，玩家会反复尝试无效操作；
- 不能只用锁图标表达权限，节点底座或材质也应区分。

## 4. 解法空间：八个维度共同形成的结果

关卡最终难度不仅取决于单个旋钮，还取决于解法空间。

需要检查：

- 是否存在多个同分解；
- 是否有保底、优化和完美三档方案；
- 是否存在诱人但无法全亮的局部最优；
- 是否必须使用某一种关键件；
- 是否能用更多导线替代稀缺中转件；
- 是否存在绕过核心考点的廉价直连解；
- 玩家第一次失败后，能否判断自己缺的是数值、空间、元件还是线长。

多解不是漏洞。理想状态是：

> 玩家可以用不同结构获得相同成绩，但想拿满分必须理解本关核心机制。

## 5. 难度组合原则

### 5.1 一主、一冲突、一宽松

每关建议写明：

- **主考维度**：玩家这一关主要应该学会或证明什么；
- **冲突维度**：用哪个旧维度让主考点产生取舍；
- **宽松维度**：哪个维度保持容错，避免信息同时拉满。

示例：

> 主考“分流数值”，用“空间落点”制造冲突，导线预算保持宽松。

### 5.2 推荐组合

| 主考 × 冲突 | 典型题目 |
|---|---|
| 空间 × 拓扑 | 数学结构正确，但关键元件会堵住唯一通道 |
| 数值 × 中转件预算 | 知道如何拼数，但合流器数量不足 |
| 空间 × 导线预算 | 十字件是短解，外圈绕行是保底解 |
| 数值 × 多目标 | 同一电源可以组成两套答案，但输出 Pin 不能复用 |
| 固定骨架 × 资源 | 保留旧件省元件，重新搭建省导线 |
| 多目标 × 空间 | 前两个目标容易点亮，最后一个会占用关键通道 |
| Pin × 拓扑 | 元件位置充足，但入口朝向迫使线路调整连接顺序 |

### 5.3 不推荐组合

以下组合容易同时拉高认知和操作负担：

- 精确数值 × 极限导线预算 × 多条交叉；
- 新分流规则 × 新合流规则 × 固定骨架；
- 大画布 × 多目标 × 大量无用件；
- 隐蔽 Pin 朝向 × 单格窄道；
- 唯一解 × 删除/移动后需要大量重画。

## 6. 教学关、普通关与综合关

### 教学关

- 只引入一个新规则；
- 主考维度明确；
- 其他维度保持宽松；
- 正确操作立即产生可见反馈；
- 不要求极限预算；
- 尽量避免多个近似错误答案。

### 普通关

- 一个已教学机制作为主考；
- 一个旧机制制造冲突；
- 至少保留一种可解释的替代解；
- 允许部分完成；
- 失败后可以局部修改，而非全部推倒。

### 综合关

- 组合两个已掌握机制；
- 通过多目标形成保底、优化、完美三档；
- 可以收紧一种资源预算；
- 应以拓扑或取舍增加深度，不以数值规模增加负担；
- 需要保留策划解法与导线格数基线。

---

## 7. 伪难度与红线

下列做法通常不会增加有效思考：

- 单纯扩大画布或拉长线路；
- 隐藏电量、Pin 朝向或分组关系；
- 使用大量复杂数字增加口算；
- 导线预算精确到一格不差；
- 堆放很多没有用途的中转件；
- 依靠重复描线、误操作或撤销成本；
- 用低对比背景隐藏可走区域；
- 同一关同时要求精确算术、极限线长、复杂交叉和固定骨架；
- 把当前尚未实现的机制当成资产配置使用。

当前不能仅靠关卡配置实现的难度包括：时间机制、线路过载、不同电属性、节点旋转、跨局保存电路，以及按少用线/少用件直接计算额外分数。

## 8. 难度评审与实玩观察

### 8.1 设计评审问题

1. 主考维度是什么？
2. 冲突维度是什么？
3. 哪个维度有意保持宽松？
4. 保底、优化、完美解分别是什么？
5. 玩家第一次失败后能否知道原因？
6. 是否存在绕过核心考点的直连解？
7. 是否存在有意保留的替代解？
8. 关键预算比策划解留了多少容错？
9. 这关是在考思考，还是只在增加描线工作量？
10. 题面为什么像“修理设备”，而不是一张抽象数学图？

### 8.2 实玩记录

建议至少记录：

- 首次完成时间；
- 首次达到任意分数的时间；
- 首次达到满分的时间；
- 第一次卡住的原因；
- 是否理解电量变化；
- 是否发生大面积推倒重画；
- 使用了哪些件、多少导线格；
- 玩家是否能复述自己的解法；
- 玩家认为困难来自哪里；
- 玩家是否愿意继续优化。

如果玩家实际卡点与设计主考维度不同，优先检查信息反馈和题面构图，不要直接增加提示或降低所有预算。

## 10. Demo 范围建议

Demo 首批关卡不需要覆盖八个维度的全部高难形态。建议优先验证：

1. 空间占位与转向；
2. 整除分流；
3. 空出口或余数损耗；
4. 两路合流；
5. 十字交叉与绕行取舍；
6. 四目标的部分完成与满分优化；
7. 一张具备固定骨架的主题化维修关。

首批内容的目标不是证明系统可以做得很难，而是验证玩家是否能读懂规则、感受到取舍，并愿意为了更完整的修复结果主动优化线路。
